# know —— 你的资料放这里

程序启动时会索引本文件夹里的所有资料（`.docx` / `.pdf` / `.txt` / `.md`），
把题目、笔记、手册丢进来即可，重启后生效。

- 有 `第N题 … 【参考答案】` 结构的 Word/PDF 会被切成问答条目；
- 没有题目结构的资料会按约 1200 字切块，作为“资料片段”参与检索；
- 扫描版 PDF 会用 Windows OCR 补文本层（单文件最多 60 页 / 150 秒，结果有缓存）；
- `README` 或 `_` 开头的说明文件不会当作资料。

> 本仓库不附带任何题库/资料（体积大且版权各自归属），请只放你有权使用的文件。
